# Stepa Estate — лендинг, недвижимость на Пхукете

Статический сайт: `index.html`, `styles.css`, `script.js`, `privacy.html`, фото в `assets/`.

- Заявки: `LEAD_ENDPOINT` в первой строке `script.js` (Cloudflare Worker, ref `TW4LB5RQYK`), клиент активирует бота по ссылке `https://t.me/formsfeedback_bot?start=TW4LB5RQYK`.
- Шрифт: Onest (в выданном при отборе Archivo нет кириллицы).
- Фото: реальные снимки Пхукета из Wikimedia Commons, авторство в подвале страницы и в `assets/credits.json`. Заменить на собственные фото клиента при их получении.
- Калькулятор окупаемости: пример для прикидки, цифры подставляет посетитель.
- Заглушки/уточнить: Telegram или WhatsApp для связи, адрес офиса и часы работы (на сайте только Пхукет, телефон, почта), ответственное лицо в политике конфиденциальности (сейчас Гараев М. В. из брифа, а в соцсетях страницы ведёт Андрей Степочкин).
